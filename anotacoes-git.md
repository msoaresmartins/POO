# Anotações da prática

Este arquivo foi criado no ramo `pratica-git`.

- `git clone` copia o repositório do GitHub para o computador.
- `git add` seleciona os arquivos que vão entrar no próximo commit.
- `git commit` registra uma versão local com uma mensagem.
- `git push` envia os commits para o GitHub.
- `git branch` cria ou lista ramos.
- `git checkout` troca o ramo em uso.

Nesta prática, deixei esta anotação no segundo ramo para comparar com a `main`.
